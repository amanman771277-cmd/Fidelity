📌 Firestore Security Rules (ለሕዝብ ክፍት ንባብ እና ጽሕፈት / Public Read & Write):

በቀጥታ ለሚጎበኙ እንግዶች ሁሉም የተለጠፉ ሥራዎች እንዲታዩ እና ከአድሚን ፓናል የሚደረጉ ለውጦች ወዲያውኑ እንዲመሳሰሉ በFirebase Console > Firestore Database > Rules ውስጥ የሚከተለውን ደንብ ያስገቡ: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /posts/{postId} {
      allow read: if true;
      allow create, update, delete: if true;
    }
  }
}
